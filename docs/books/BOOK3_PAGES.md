# p36: Grown-up corner

## What the Cloud Town friends really are

| Cloud Town character | Real AWS service | The grown-up layer |
|---|---|---|
| **Boxy** | **Amazon Elastic Container Service (Amazon ECS)** | Runs and manages containerized applications, placing tasks on available compute and replacing tasks when they stop. |
| **Kira** | **Amazon Elastic Kubernetes Service (Amazon EKS)** | Provides a managed Kubernetes control plane for running and coordinating Kubernetes workloads on AWS. |
| **Fay** | **AWS Fargate** | Provides serverless compute for containers with ECS or EKS, so teams do not manage the underlying servers and pay for requested resources while workloads run. |
| **Mapi** | **Amazon Route 53** | Provides DNS, health checks, and routing policies that direct users to healthy application endpoints. |
| **Zip** | **Amazon CloudFront** | A content delivery network that caches content at edge locations so it reaches users with lower latency. |
| **Boost** | **AWS Global Accelerator** | Gives applications static anycast IP addresses and routes traffic across the AWS global network to an optimal healthy regional endpoint. |
| **Seal** | **AWS Certificate Manager (ACM)** | Provisions, stores, deploys, and renews TLS certificates used with integrated AWS services to help protect network connections. |
| **Winn** | **Amazon API Gateway** | Creates a managed front door for APIs, with request routing, authorization options, throttling, and monitoring. |
| **Poppy** | **AWS Amplify** | Helps teams build, deploy, and host web and mobile application front ends, with managed workflows that connect the pieces. |

The book uses toys, roads, doors, stickers, and a lemonade stand to make each job visible to young readers. The real services are flexible building blocks, and architects often use several of them together.
